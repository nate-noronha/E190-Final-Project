# Reflect Skill

When documenting process and engineering progress:
1. Ensure `PROCESS.md` exists in the repository root.
2. Append a clean, timestamped entry summarizing:
   - Slice / task name
   - Agent harness used (Antigravity subagent, Claude Code CLI, or human pair)
   - Architectural decisions & compliance with `CLAUDE.md` / `AGENTS.md`
   - Test results & verification status
   - Next actionable steps
